Topic: The order of lighting the Hanukkah candles

Sources: The Gemara; Rambam; Shulhan Arukh; the Arizal; the Vilna Gaon

Daily Halacha: Hanukkah

These notes are based on an automatic transcript of the recording.

The halacha

  • The Gemara, codified by Rambam, says that whenever one turns, one turns to the right, so where there is a choice one goes from left to right.
  • The Shulhan Arukh rules that each night one begins with the furthest left candle, the new candle of the night, then moves right: on the third night candle three, then two, then one; on the eighth night from the far left back to candle one.
  • The Shulhan Arukh adds a second reason: each night there is a new miracle, so the berakhah and the first lighting go on the new candle.
  • This is the universal practice of the Sepharadim, and the Arizal held so too.
  • The Vilna Gaon disagreed. The core misvah is one candle (one candle each night suffices if one is stuck); the rest are mehadrin. So one should say the berakhah on and begin with candle one, then go right to left. The Shulhan Arukh would answer: who says the first is the main one?
  • The Vilna Gaon adds that the Menorah should be as near as possible to the doorway, and the first, rightmost candle is nearest to it.
  • Among Ashkenazim practices differ. He believes the main Ashkenazi practice is like the Sepharadim, but some communities go right to left, with the berakhah on candle one.

In one line

Sepharadim say the berakhah on the new candle and light from left to right; some Ashkenazim, following the Vilna Gaon, start from candle one.
